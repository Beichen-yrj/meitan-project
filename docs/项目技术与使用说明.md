# 煤层瓦斯智能分析平台：项目技术与使用说明

## 1. 项目概述

本平台用于煤层瓦斯数据处理、吸附参数分析和突出危险性检测，主要功能包括：

- 瓦斯吸附含量计算与分析
- 煤样瓦斯吸附参数统计分析
- 煤层瓦斯突出危险性检测
- 计算数据文件管理
- 瓦斯数据导出与报告
- AI 助手“小瓦”
- 用户反馈与管理员反馈处理
- 管理员用户、黑名单和登录日志管理

系统采用前后端分离架构。Vue 前端负责页面、Excel 解析、图表和浏览器本地计算；Spring Boot 后端负责账号、权限、反馈、文件和 AI 接口；Python 服务提供可选的服务端科学计算 API。

## 2. 技术栈

### 2.1 前端

| 技术 | 主要作用 |
| --- | --- |
| Vue 3.4、Vite 5.4 | 页面开发、开发服务器和生产构建 |
| Element Plus 2.5 | 表单、表格、菜单和弹窗 |
| Vue Router 4.3 | 页面路由和管理员权限拦截 |
| Pinia 2.1 | 登录用户状态及持久化 |
| ECharts 5.5、vue-echarts 6.7 | 数据图表 |
| Axios 1.6 | 后端 API 请求 |
| SheetJS xlsx 0.18 | XLSX、XLS、CSV 导入和 XLSX 导出 |

### 2.2 Java 后端

| 技术 | 主要作用 |
| --- | --- |
| Java 17、Spring Boot 3.2 | REST API 和业务服务 |
| Spring Security | BCrypt 密码加密和接口安全 |
| MyBatis-Plus 3.5 | MySQL 数据访问和分页 |
| JJWT 0.12 | JWT 登录令牌 |
| Hutool、Apache POI | 文件和 Excel 处理 |
| Lombok | 简化实体类和服务代码 |

### 2.3 Python 计算服务

- Flask、Flask-CORS：计算 HTTP API
- NumPy、Pandas：数值和表格分析
- Matplotlib：服务端图表
- OpenPyXL：Excel 读取

### 2.4 数据与安全

- 数据库：MySQL，默认数据库名为 `meitan`。
- 登录认证：JWT。
- 用户密码：BCrypt。
- DeepSeek API Key：只保存在当前浏览器会话中。
- 计算历史：按用户 ID 隔离，每个账号最多 50 条，超过 60 天自动清理。

## 5. 开发环境启动

### 5.1 环境要求

- JDK 17、Maven 3.8+
- MySQL 8.0+
- Node.js 18+、npm 9+
- Python 3.10+（Python 服务可选）

### 5.2 初始化数据库

执行 `meitan/sql/init.sql`，然后检查 `meitan-server/src/main/resources/application.yml` 中的数据库连接。初始管理员信息以初始化脚本为准，首次登录后应立即修改密码。

```powershell
cd .\meitan
mysql -u root -p < .\sql\init.sql
```

### 5.3 启动 Java 后端

```powershell
cd .\meitan\meitan-server
mvn spring-boot:run
```

默认地址：`http://localhost:8080`

### 5.4 启动前端

```powershell
cd .\meitan\meitan-web
npm install
npm run dev
```

默认地址：`http://localhost:3000`，`/api` 会代理到 8080。

### 5.5 启动 Python 服务（可选）

前端当前默认使用 `localGasCalculation.js` 本地计算，不强制启动 Python。测试服务端计算接口时执行：

```powershell
cd .\meitan\meitan-python
python -m pip install -r requirements.txt
python app.py
```

默认地址：`http://localhost:5000`，健康检查为 `/health`。

## 6. 网站使用教程

### 6.1 登录与注册

1. 已有账号直接登录。
2. 新用户点击“立即注册”，填写用户名、密码、真实姓名和邮箱。
3. 被禁用或加入黑名单的账号不能登录。

### 6.2 瓦斯吸附含量计算与分析

1. 进入“瓦斯吸附含量计算与分析”。
2. 页面自动读取内置 `data(3).xlsx`，从下拉框选择煤型及编号、挥发分。
3. 使用自己的数据时，点击“加载参数文件”，导入 XLSX、XLS 或 CSV。
4. 设置温度、含水率、Langmuir 参数和压力范围。
5. 点击“开始计算并绘图”。
6. 可切换图表类型，点击图表放大，并保存图片或导出 XLSX。

### 6.3 煤样瓦斯吸附参数统计分析

1. 页面默认读取 `地区数据yyy(1).xlsx`。
2. 从 Excel 生成的下拉框选择地区和挥发分。
3. 设置图表类型、坐标轴、颜色字段和大小字段。
4. 点击绘图，完成后可放大、保存或导出。

### 6.4 煤层瓦斯突出危险性检测

1. 导入包含压力和吸附瓦斯数据的 XLSX、XLS 或 CSV。
2. 设置孔隙容积、压缩系数和临界值。
3. 点击“计算游离瓦斯及总含量”。
4. 查看总瓦斯曲线和危险性判断，并可放大、保存、导出。

### 6.5 数据文件管理

1. 三个计算模块成功计算后自动保存记录。
2. 可按模块筛选、查看参数与明细、导出或删除记录。
3. “清除全部”只清除当前账号的数据。
4. 不同账号记录互相隔离；最多 50 条，超过 60 天自动清理。

### 6.6 数据导出与报告

1. 先完成一个或多个模块的计算。
2. 进入“瓦斯数据导出与报告”。
3. 查看最近记录和综合评价。
4. 导出 XLSX 综合报告或 HTML 浏览器报告。

### 6.7 AI 助手“小瓦”

1. 点击并拖拽煤炭助手图标。
2. 在“设置与教程”中填写自己的 DeepSeek API Key。
3. Key 只保存在当前浏览器会话，不写入数据库。
4. 可询问操作和瓦斯知识，也可让小瓦跳转到指定页面。
5. `A-`、`A+` 调整字体，“朗读”使用浏览器中文语音。
6. DeepSeek Key 创建地址：[DeepSeek API Keys](https://platform.deepseek.com/api_keys)。

### 6.8 用户反馈

1. 选择 1 至 5 星并填写反馈内容。
2. 提交后可查看“待处理”“处理中”“已解决”状态。
3. 管理员回复会显示在用户的反馈记录中。

### 6.9 管理员功能

- 用户管理：查看统计、启用禁用、黑名单和登录日志。
- 反馈处理：搜索筛选、修改状态和回复用户。
- 管理员入口只对 `ADMIN` 角色显示。

## 7. 常见问题

### 7.1 8080 端口被占用

停止旧后端进程后重新启动，或修改 `application.yml` 中的 `server.port`。

### 7.2 前端接口无法访问

确认 Java 后端运行在 8080，并检查 Vite `/api` 代理。

### 7.3 Excel 下拉框没有内容

确认文件为 XLSX、XLS 或 CSV，并检查表头中是否包含页面需要的煤型、地区、挥发分、压力等字段。

### 7.4 图表没有生成

检查必填参数、压力范围和导入数值。完成计算后点击图表即可放大。

### 7.5 小瓦请求失败

检查 DeepSeek API Key、账户余额、Java 后端和网络连接。

## 8. 构建与部署

```powershell
# 前端构建
cd .\meitan\meitan-web
npm run build

# 后端测试与打包
cd ..\meitan-server
mvn clean test
mvn clean package
```

生产环境必须修改数据库凭据、JWT 密钥和初始管理员密码，并为数据库、上传文件和重要报告建立备份。`dist/`、`target/`、日志、Python `__pycache__/` 和 npm 缓存均可重新生成，不应长期作为源码保存。
