# 煤层瓦斯智能分析平台 — 使用教程

## 一、快速开始

### 1.1 访问平台

浏览器打开 `http://121.43.115.221`（或你的域名），进入登录页面。

### 1.2 账号说明

| 角色 | 权限范围 |
|------|----------|
| **普通用户** | 瓦斯计算、统计分析、危险性检测、文件管理、个人中心、反馈 |
| **管理员** | 普通用户全部权限 + 用户管理 + 新闻管理 + 反馈处理 |

> 管理员账号需向系统管理员申请开通。普通用户可自主注册。

---

## 二、普通用户操作

### 2.1 注册与登录

1. 在登录页点击「注册」按钮
2. 填写用户名、密码、真实姓名
3. 注册成功后自动跳转登录
4. 输入账号密码，点击登录

### 2.2 瓦斯吸附含量计算

1. 左侧菜单进入「瓦斯吸附计算」
2. 填写参数：
   - **Langmuir 体积 Vm**：煤样的最大吸附量（cm³/g）
   - **Langmuir 压力常数 Pl**：吸附量达到一半时的压力（MPa）
   - **压力范围**：计算的压力区间起止值
   - **煤质校正系数 α** 和 **温度校正系数 λ**
3. 点击「开始计算」
4. 查看结果：P-Vm 原始数据表 + 等温吸附曲线图

### 2.3 煤样参数统计分析

1. 左侧菜单进入「参数统计分析」
2. 点击上传 Excel 文件（格式：一行为一个样本，一列为一个参数）
3. 选择图表类型：散点图 / 双轴图 / 分组对比图
4. 点击「开始分析」
5. 查看生成的统计图表和汇总数据

### 2.4 突出危险性检测

1. 左侧菜单进入「危险性检测」
2. 填写参数：
   - **瓦斯压力 P**（MPa）
   - **煤孔隙率 A**
   - **温度 T**（K）
3. 点击「开始评估」
4. 查看结果：
   - 游离瓦斯含量 Xy
   - 是否达到临界值（**超标项标红**）
   - 检测结论（安全 / 需要关注 / 危险）

### 2.5 文件管理

1. 左侧菜单进入「文件管理」
2. 点击上传按钮，选择模块（吸附分析 / 统计分析 / 检测评估）
3. 选择本地文件上传
4. 可对已有文件执行删除操作

### 2.6 个人中心

1. 左侧菜单进入「个人中心」
2. **修改个人信息**：可更新真实姓名、邮箱、手机号
3. **修改密码**：输入原密码和新密码

### 2.7 反馈

1. 左侧菜单进入「意见反馈」
2. 填写反馈内容，提交
3. 管理员会处理并回复

## 三、AI 智能助手「小瓦」

页面右下角有一个煤炭精灵造型的浮动按钮，这就是 AI 助手「小瓦」。所有用户都能使用。

### 3.1 首次配置（只需一次）

1. 点击右下角的煤炭精灵图标，打开对话面板
2. 点击面板右上角齿轮图标，进入 API 设置
3. 按弹窗中的教程步骤操作：
   - 前往 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 注册/登录
   - 创建 API Key（以 `sk-` 开头），立即复制
   - 粘贴到输入框，点击「保存并使用」
4. Key 仅保存在当前浏览器会话中，关闭浏览器后失效，不会上传到服务器

> API Key 需在 DeepSeek 平台充值后才能调用，费用很低（约 1 元/百万 token）。

### 3.2 拖拽移动

鼠标按住煤炭精灵可以拖动到屏幕任意位置，松开即可固定。再次点击打开/关闭对话框。

### 3.3 对话问答

- 底部输入框直接打字提问，回车或点击发送
- 问平台操作："如何计算吸附含量？""在哪里上传文件？"
- 问瓦斯知识："什么是 Langmuir 吸附模型？""瓦斯突出的判定标准是什么？"
- 小瓦会自动识别你的意图，**在当前页面和语境下给出针对性回答**

### 3.4 页面导航

- 点击工具栏「页面导航」按钮，显示 9 个功能入口快捷网格
- 或者直接对着小瓦说"带我去统计分析"、"前往个人中心"
- 小瓦会在回复中附上导航按钮，点击即跳转

### 3.5 快捷提问

对话框底部有 3 个快捷按钮，点击即可一键发送常见问题。

### 3.6 文字大小 & 朗读

- **A− / A＋**：调整对话文字大小（14px ~ 20px）
- **朗读开关**：开启后小瓦每次回复会自动语音朗读
- **单条朗读**：每条回复下方有「朗读」按钮，可单独播放

> 朗读功能依赖浏览器内置语音引擎（Web Speech API），中文语音效果以 Chrome/Edge 浏览器最佳。

### 3.7 未配置 Key 也能用

即使没有 DeepSeek API Key，小瓦仍能根据你的问题关键词智能匹配对应功能页面，并给出导航按钮引导你前往。

## 四、管理员操作

管理员登录后，侧边栏会额外显示以下菜单。

### 4.1 用户管理

1. 进入「用户管理」
2. 查看所有注册用户列表（用户名、真实姓名、角色、状态、登录次数）
3. **操作**：
   - 启用/禁用用户：点击状态开关
   - 加入/移出黑名单：点击黑名单按钮
   - 查看登录日志：了解用户登录历史

### 4.2 新闻管理

1. 进入「新闻管理」
2. **新增新闻**：填写标题、链接、来源、排序
3. **编辑新闻**：点击编辑按钮修改
4. **删除新闻**：点击删除按钮
5. 首页新闻列表实时同步更新

### 4.3 反馈处理

1. 进入「反馈管理」
2. 查看所有用户提交的反馈
3. 标记反馈状态（待处理 → 已处理）

### 4.4 管理员自己的计算

管理员同样可以使用所有计算功能（瓦斯吸附、统计分析、危险性检测），操作方式与普通用户一致。

## 五、常见问题

| 问题 | 解决方法 |
|------|----------|
| 忘记密码 | 联系管理员重置（暂不支持自助找回） |
| 登录失败提示"用户不存在" | 检查用户名，未注册请先注册 |
| 登录失败提示"密码错误" | 核对密码，注意大小写 |
| 计算无结果 | 检查参数是否填写完整，确保 Python 计算服务运行正常 |
| 上传 Excel 报错 | 检查文件格式，必须是 .xlsx 或 .xls |
| 页面无法访问 | 检查服务器是否正常运行，联系管理员 |
| 小瓦回复"无法连接 DeepSeek" | 检查 API Key 是否有效、账户余额是否充足 |
| 小瓦朗读没声音 | 确认浏览器支持 Web Speech API（推荐 Chrome/Edge） |
