# 阿里云服务器部署指南（Ubuntu 22.04）

> 操作系统：Ubuntu 22.04 LTS | 代码通过 GitHub `git clone/pull` 拉取

---

## 一、服务器选购与安全组

### 1.1 推荐配置

| 配置项 | 最低 | 推荐 |
|--------|------|------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 系统盘 | 40 GB | 80 GB |
| 带宽 | 5 Mbps | 10 Mbps |

### 1.2 安全组规则

阿里云控制台 → 安全组 → 入方向添加规则：

| 端口 | 来源 | 用途 |
|------|------|------|
| 22 | 0.0.0.0/0 | SSH |
| 80 | 0.0.0.0/0 | HTTP |
| 443 | 0.0.0.0/0 | HTTPS |

> Spring Boot (:8080) 和 Python Flask (:5000) 只监听 127.0.0.1，不暴露公网，由 Nginx 反向代理统一对外。

## 二、基础环境安装

### 2.1 SSH 连接 & 更新系统

```bash
ssh root@你的公网IP
apt update && apt upgrade -y
```

### 2.2 一键安装所有依赖

```bash
apt install -y vim curl wget git openjdk-17-jdk mysql-server \
    python3-pip python3-venv nginx certbot python3-certbot-nginx \
    maven nodejs npm
```

> `maven` 和 `nodejs/npm` 用于后续在服务器上直接构建后端 jar 和前端 dist，配合 `update.sh` 实现一键自动更新部署。如不安装，则需在本地构建后用 `scp` 上传产物。

> ⚠️ **注意 Node.js 版本**：Ubuntu 22.04 默认 `apt install nodejs` 装的是 12.x，太旧，Vite 5 构建会报 `Unexpected reserved word` 错误。**必须升级到 Node 18 LTS**，方法见 2.3 节。

### 2.3 升级 Node.js 到 18 LTS（前端构建必需）

```bash
# 1. 卸载旧版 Node 及冲突包
apt remove -y libnode-dev libnode72 nodejs nodejs-doc
apt autoremove -y

# 2. 添加 NodeSource 18.x 源并安装
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs

# 3. 验证版本（应显示 v18.x.x）
node -v
npm -v
```

### 2.4 配置 SSH 密钥访问 GitHub

> 使用 Ed25519 算法，比 RSA 更安全、密钥更短。

```bash
ssh-keygen -t ed25519 -C "server@meitan" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub
```

复制公钥内容 → 浏览器打开 [GitHub SSH Keys](https://github.com/settings/keys) → New SSH Key → 粘贴 → Add。

测试连接：

```bash
ssh -T git@github.com
# Hi xxx! You've successfully authenticated...
```

## 三、数据库配置

### 3.1 启动 MySQL

```bash
systemctl start mysql
systemctl enable mysql
mysql_secure_installation
```

按提示操作（如果没出现密码设置步骤，说明使用了 `auth_socket` 插件，见下方说明）：

- `VALIDATE PASSWORD COMPONENT` → `n`
- `New password` → 输入并确认 root 密码（可能不出现此步骤）
- 后续全部 `y`

> 如果 `mysql_secure_installation` 没有提示设置密码，说明 MySQL 使用 `auth_socket` 认证，root 只能通过系统 root 用户免密登录，无需密码。这是 Ubuntu 22.04 的默认行为，不影响后续操作，直接继续即可。

### 3.2 创建数据库和应用账号

```bash
# auth_socket 模式直接免密登录；如果设过密码则用 mysql -u root -p
sudo mysql
```

```sql
CREATE DATABASE IF NOT EXISTS meitan DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'meitan'@'localhost' IDENTIFIED BY 'Meitan@2026!';
--                                        ↑ 自己设一个密码，建议包含大小写字母+数字+符号
GRANT ALL PRIVILEGES ON meitan.* TO 'meitan'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 3.3 克隆项目并初始化数据表

```bash
cd /opt
git clone git@github.com:你的用户名/仓库名.git meitan

# 用 root 导入，init.sql 含 CREATE DATABASE 等需要全局权限的语句
sudo mysql < /opt/meitan/sql/init.sql
```

## 四、部署 Python 计算服务

```bash
cd /opt/meitan/meitan-python
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

配置 systemd：

```bash
vim /etc/systemd/system/meitan-python.service
```

```ini
[Unit]
Description=Meitan Python Calculation Service
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/meitan/meitan-python
ExecStart=/opt/meitan/meitan-python/venv/bin/python app.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl start meitan-python
systemctl enable meitan-python
curl http://localhost:5000/health
# {"status":"ok","service":"meitan-python-service"}
```

## 五、部署 Spring Boot 后端

> 后端 jar 包需本地 `mvn package` 构建后上传，不在服务器装 Maven。

### 5.1 本地构建 jar

```bash
# 本地执行
cd meitan-server
mvn clean package -DskipTests
```

### 5.2 创建生产配置 & 上传 jar

服务器上：

```bash
mkdir -p /opt/meitan-server
vim /opt/meitan-server/application-prod.yml
```

```yaml
server:
  port: 8080

spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/meitan?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: meitan
    password: Meitan@2026!    # 与上一步 CREATE USER 时的密码一致

jwt:
  secret: 生产环境务必替换-用openssl rand -base64 64生成
  expiration: 86400000

python:
  service:
    url: http://localhost:5000

file:
  upload:
    path: /opt/uploads
```

> 生成 JWT 密钥：`openssl rand -base64 64`

本地上传 jar：

```bash
# 本地执行
scp meitan-server/target/*.jar root@你的IP:/opt/meitan-server/
```

### 5.3 配置 systemd

```bash
vim /etc/systemd/system/meitan-server.service
```

```ini
[Unit]
Description=Meitan Spring Boot Server
After=network.target mysql.service meitan-python.service
Wants=mysql.service meitan-python.service

[Service]
Type=simple
WorkingDirectory=/opt/meitan-server
ExecStart=/usr/bin/java -jar -Dspring.profiles.active=prod /opt/meitan-server/meitan-server-1.0.0.jar
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl start meitan-server
systemctl enable meitan-server
journalctl -u meitan-server -f    # 看到 Started MeitanApplication 后 Ctrl+C
```

### 5.4 创建上传目录

```bash
mkdir -p /opt/uploads && chmod 755 /opt/uploads
```

## 六、部署 Vue 前端

> 前端在本地 `npm run build` 构建后上传 `dist/`，不在服务器装 Node.js。

### 6.1 本地构建

```bash
# 本地执行
cd meitan-web
npm run build
```

### 6.2 上传 & 配置 Nginx

```bash
# 本地执行
scp -r meitan-web/dist/* root@你的IP:/var/www/meitan/
```

服务器上：

```bash
mkdir -p /var/www/meitan
vim /etc/nginx/sites-available/meitan
```

```nginx
server {
    listen       80;
    server_name  _;                     # 有域名改为你的域名

    charset utf-8;
    client_max_body_size 20M;

    root   /var/www/meitan;
    index  index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_connect_timeout 60s;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/meitan /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl restart nginx
```

### 6.3 验证

浏览器访问 `http://你的公网IP`，用 `admin / admin123` 登录。

              ▼

## 十、日常运维

### 10.1 服务管理

```bash
systemctl status nginx mysql meitan-server meitan-python  # 查看全部状态
systemctl restart meitan-server                            # 重启后端
systemctl restart meitan-python                            # 重启 Python
systemctl restart nginx                                    # 重启 Nginx
journalctl -u meitan-server -f                             # 后端实时日志
```

### 10.2 更新部署

服务器上执行自带的 `update.sh` 脚本即可完成全自动更新：

```bash
# 首次使用赋予执行权限（只需一次）
chmod +x /opt/meitan/update.sh

# 以后每次更新只需
bash /opt/meitan/update.sh
```

脚本自动执行 5 步：

| 步骤 | 操作 |
|------|------|
| 1 | `git pull` 拉取 GitHub 最新代码 |
| 2 | `sudo mysql < sql/init.sql` 更新数据库 |
| 3 | `mvn clean package` 构建后端 → 复制 jar 到 `/opt/meitan-server/` |
| 4 | `npm run build` 构建前端 → 复制 dist 到 `/var/www/meitan/` |
| 5 | `systemctl restart` 重启 Python 和后端服务 |

> 如果服务器未安装 Maven 或 Node.js，脚本会跳过对应构建步骤，仅重启已有的服务。如需完整自动构建，先在服务器安装：`apt install maven nodejs npm -y`

### 10.3 数据库备份

```bash
mkdir -p /opt/backups

# 手动备份
mysqldump -u meitan -p meitan > /opt/backups/meitan_$(date +%Y%m%d_%H%M).sql

# 恢复
mysql -u meitan -p meitan < /opt/backups/meitan_20260802_0300.sql
```

**定时备份（每天凌晨 3 点）：**

```bash
crontab -e
```

```cron
0 3 * * * mysqldump -u meitan -p密码 meitan > /opt/backups/meitan_$(date +\%Y\%m\%d).sql
0 4 * * 0 find /opt/backups/ -name "*.sql" -mtime +30 -delete
```

## 十二、从头部署速览

```bash
# === 服务器上一次性执行 ===
ssh root@你的IP

# 1. 基础环境
apt update && apt upgrade -y
apt install -y git openjdk-17-jdk mysql-server python3-pip python3-venv nginx certbot python3-certbot-nginx

# 2. GitHub SSH 密钥（Ed25519）
ssh-keygen -t ed25519 -C "server@meitan" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub
# → 复制公钥到 https://github.com/settings/keys

# 3. MySQL
systemctl start mysql && systemctl enable mysql
mysql_secure_installation
mysql -u root -p -e "
  CREATE DATABASE IF NOT EXISTS meitan CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'meitan'@'localhost' IDENTIFIED BY '你的密码';
  GRANT ALL ON meitan.* TO 'meitan'@'localhost'; FLUSH PRIVILEGES;"

# 4. 克隆代码 & 初始化数据库
cd /opt
git clone git@github.com:你的用户名/仓库名.git meitan
sudo mysql < /opt/meitan/sql/init.sql

# 5. Python 服务
cd /opt/meitan/meitan-python
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
# → 配置 systemd: /etc/systemd/system/meitan-python.service

# 6. 后端（需本地 mvn package 后 scp jar 上传）
# → 配置 /opt/meitan-server/application-prod.yml
# → 配置 systemd: /etc/systemd/system/meitan-server.service

# 7. 前端（需本地 npm run build 后 scp dist/ 上传）
# → 配置 Nginx: /etc/nginx/sites-available/meitan

# 8. 全部启动
systemctl daemon-reload
systemctl start mysql meitan-python meitan-server nginx
systemctl enable mysql meitan-python meitan-server nginx

# 9. HTTPS
certbot --nginx -d 你的域名.com

echo "部署完成: https://你的域名.com"
```
