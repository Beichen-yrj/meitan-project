## 二、修改概述

本次修改主要解决以下问题：

1. 更新新闻资讯页面中的政策链接。
2. 各计算模块不再自动加载原始文件，改为由用户主动选择文件。
3. 优化瓦斯吸附量计算与分析页面的参数名称和煤样选择逻辑。
4. 限制煤层瓦斯吸附参数统计的坐标轴选项，并改进地区、颜色和大小的比较方式。
5. 重构煤层区域突出危险性预测逻辑，使导入的吸附数据真正参与危险性判定。
6. 统一图表曲线、图例、临界值标记和实测值标记。
7. 同步更新数据文件管理、历史记录、结果导出和综合报告。

## 四、文件加载方式

### 4.1 通用调整

- 各计算页面不再自动加载原文件。
- 用户必须主动选择本地 Excel 或 CSV 文件后才能计算。
- 加载新文件后，旧图表和旧计算结果会被清除，避免不同文件的数据混用。

### 4.2 样板文件

| 模块 | 样板文件处理 |
|------|--------------|
| 瓦斯吸附量计算与分析 | 上传按钮旁保留样板文件下载入口 |
| 煤层瓦斯吸附参数统计 | 上传按钮旁保留样板文件下载入口 |
| 煤层区域突出危险性预测 | 不显示样板文件或参考文件下载入口，只保留数据导入按钮 |

## 五、瓦斯吸附量计算与分析

### 5.1 页面文字

- “煤型参数”修改为“基础参数”。
- “煤型及编号”修改为“煤样编号”。
- 煤样显示文本中去除多余的“及”字。
- 删除“参考温度”整行，计算时内部固定使用 `25°C`。

### 5.2 煤样编号选择

- 页面初始状态不预置煤样编号。
- 用户导入文件后，系统读取文件中的煤样名称。
- 下拉菜单只显示当前导入文件内实际存在的煤样编号。
- 切换文件后，下拉菜单随新文件内容重新生成。

### 5.3 图表

- 计算曲线不再显示圆形数据点。
- 图例使用与实际曲线一致的线段符号。

## 六、煤层瓦斯吸附参数统计

### 6.1 坐标轴限制

| 选项 | 可选内容 |
|------|----------|
| X 轴 | 挥发分、水分 |
| Y 轴 | VL值、PL值 |

散点图标题按“Y轴/X轴”显示，默认标题为“VL值/挥发分”。

### 6.2 地区比较

原单地区筛选已改为多地区比较：

- 地区选择框支持搜索、多选和清空。
- 不选择任何地区时，显示全部地区数据。
- 选择一个或多个地区时，只显示所选地区的数据。
- 用户可以只选择少量地区进行对比，避免全部地区同时着色造成图表过密。
- 历史记录和报告会以顿号连接所选地区名称。

### 6.3 颜色编码

颜色选项增加“无（默认颜色）”，并设为默认值：

- 选择“无”时，所有散点使用统一颜色。
- 选择“检索地区”等分类字段时，不同类别使用不同颜色。
- 选择数值字段时，使用连续颜色映射。
- 用户只想比较气泡大小时，可以关闭颜色编码。

### 6.4 大小编码

大小选项增加“无（默认大小）”，并设为默认值：

- 选择“无”时，所有散点保持统一大小。
- 选择数值字段时，气泡大小随数值变化。
- 用户只想比较颜色时，可以关闭大小编码，避免点大小不一影响阅读。

### 6.5 控件适用范围

- 颜色和大小编码只对散点图有效。
- 切换到双坐标轴图或分组图后，不显示颜色和大小控件。
- 双坐标轴曲线不显示圆形数据点。

## 七、煤层区域突出危险性预测

### 7.1 页面参数

- 删除游离瓦斯参数标签中的 `V`、`t`、`A` 字母，只保留中文名称和单位。
- “压力临界值”相关输入改为“实测压力值 (MPa)”。
- 删除用户手动填写“实测瓦斯含量值”的输入框。
- 增加只读的“曲线计算瓦斯含量”，计算完成后自动显示。
- 瓦斯含量临界值支持：
  - 一般区域：`W < 8 m³/t`
  - 构造带区域：`W < 6 m³/t`
  - 自定义临界值
- 压力标准值固定为 `0.74 MPa`。
- “评估结果”最终修改为“评估参考与结果”。

### 7.2 导入数据的用途

导入文件中的数据不再只用于绘图，而是直接参与危险性预测：

1. 从文件读取瓦斯压力 `P` 和吸附瓦斯量 `Xx`。
2. 根据孔隙容积、温度和压缩系数计算游离瓦斯量 `Xy`。
3. 计算总瓦斯含量曲线：

   ```text
   Q = Xx + Xy
   ```

4. 用户输入实测压力值。
5. 系统在总瓦斯含量 `Q` 曲线上，通过相邻数据点线性插值，计算该压力对应的瓦斯含量。
6. 系统自动完成压力和瓦斯含量的双指标判定。

### 7.3 线性插值

当实测压力位于两个导入压力点之间时，按下式计算对应总瓦斯含量：

```text
Q = Q1 + (P - P1) / (P2 - P1) × (Q2 - Q1)
```

其中：

- `P` 为用户输入的实测压力；
- `P1`、`P2` 为相邻的两个导入压力点；
- `Q1`、`Q2` 为两个压力点对应的总瓦斯含量。

为避免使用不可靠的外推值：

- 实测压力必须位于导入数据的最小和最大压力范围内。
- 输入框会根据当前导入文件自动限制可填范围。
- 更换文件后，如果原压力超出新文件范围，系统会自动清空该值。

### 7.4 危险性判定

判定使用以下两个条件：

| 指标 | 对比标准 |
|------|----------|
| 实测压力 | `0.74 MPa` |
| 曲线计算瓦斯含量 | 用户选择的瓦斯含量临界值 |

满足任意一个条件即判定为突出危险区：

```text
实测压力 >= 0.74 MPa
或
曲线计算瓦斯含量 >= 瓦斯含量临界值
```

只有两个指标均低于临界值时，才判定为无突出危险区。

### 7.5 预测图表

预测图表包含：

| 图形 | 样式 |
|------|------|
| 吸附瓦斯 `Xx` | 蓝色虚线，无圆点 |
| 游离瓦斯 `Xy` | 橙色虚线，无圆点 |
| 总瓦斯 `Q` | 红色实线，无圆点 |
| 压力标准值 `0.74 MPa` | 竖向虚线 |
| 瓦斯含量临界值 | 横向虚线 |
| 实测压力值 | 紫色竖向实线 |
| 曲线计算瓦斯含量 | 绿色横向实线 |

图表不再使用菱形实测点。实测值和临界值分别使用不同方向、颜色和线型展示，便于直接比较。

图例的颜色、虚实线样式与图中曲线保持一致，不再出现图例和曲线对不上的情况。

## 八、历史记录、文件管理与报告

### 8.1 历史记录

- 保存用户选择的多个地区。
- 保存实测压力和系统计算出的瓦斯含量。
- 新记录使用“曲线计算瓦斯含量”字段。
- 旧记录中的“实测瓦斯含量值”仍可兼容显示，不会导致历史数据空白。

### 8.2 数据导出

区域突出危险性预测的 Excel 导出内容包括：

- 压力 `P`
- 吸附瓦斯 `Xx`
- 游离瓦斯 `Xy`
- 总瓦斯含量 `Q`
- 实测压力值
- 压力标准值
- 曲线计算瓦斯含量
- 瓦斯含量临界值
- 预测结论及判定依据

### 8.3 综合报告

- 统计模块报告支持显示多个对比地区。
- 危险性预测报告显示曲线计算瓦斯含量。
- 对旧历史记录保留回退读取逻辑。

## 十一、使用注意事项

1. 导入文件必须包含对应模块要求的列名和有效数值。
2. 危险性预测中的实测压力必须位于导入文件的压力范围内。
3. 统计散点图若只比较地区颜色，应将“大小”设置为“无（默认大小）”。
4. 统计散点图若只比较数据大小，应将“颜色”设置为“无（默认颜色）”。
5. 地区数量较多时，建议在“地区比较”中选择少量目标地区，以减少散点重叠并提高图例可读性。
6. 压力标准值固定为 `0.74 MPa`，瓦斯含量临界值根据区域类型或自定义值确定。
