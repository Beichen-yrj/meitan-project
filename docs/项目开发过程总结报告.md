# 煤层瓦斯智能分析平台 — 开发过程总结报告

## 一、项目背景与目标

将原有 Python + Tkinter 桌面程序改造为 B/S 架构的 Web 平台，实现瓦斯吸附含量计算、煤样参数统计分析和突出危险性检测三大核心功能，提升系统的可维护性、可扩展性和多用户协作能力。

## 二、架构设计

### 2.1 整体架构（前后端分离）

```
浏览器（Vue 3 + Element Plus）
        │  HTTP/HTTPS
        ▼
    Nginx（反向代理 + 静态资源）
        │
   ┌────┴────┐
   ▼         ▼
/api/*    静态文件
   │
   ▼
Spring Boot（Java 17）
  ├─ 用户认证（JWT + BCrypt）
  ├─ 数据管理（MySQL + MyBatis-Plus）
  └─ 计算代理 ──▶ Python Flask :5000
                     ├─ Langmuir 吸附模型
                     ├─ 统计分析（numpy/pandas）
                     └─ 危险性检测
```

### 2.2 设计原则

| 原则 | 说明 |
|------|------|
| 前后端分离 | Vue 独立部署，Spring Boot 提供 RESTful API |
| 计算服务独立 | Python Flask 作为独立微服务，原科学计算代码复用 |
| 安全分层 | Nginx → Spring Security → JWT → 数据库权限 |

## 四、AI 辅助开发

### 4.1 使用的 AI 工具

| 工具 | 用途 | 使用场景 |
|------|------|----------|
| **Codex** | 代码生成、自然语言转代码 | 生成 Spring Boot Controller/Service 骨架、Python 计算函数 |
| **Trae** | 项目级开发助手、文件操作 | 批量创建项目结构、修改多文件、生成配置文件 |

### 4.2 如何向 AI 提需求

核心原则：**需求明确、上下文充分、分步迭代**。

**示例 1：项目初始化**

```
"设定工作目录为 meitan，写一份需求文档：把 Python 项目改造为 SpringBoot+Vue 架构的 Web 平台，
用 Maven 构建，MySQL + MyBatis，三大计算模块保留 Python 代码"
```

**示例 2：功能开发**

```
"写一个登录接口，POST /api/auth/login，接收 username 和 password，
查询数据库验证密码（BCrypt），返回 JWT token"
```

**示例 3：部署配置**

```
"帮我写一份 Ubuntu 22.04 的阿里云服务器部署指南，
用 git clone 拉代码，Python 和 Spring Boot 用 systemd 管理，Nginx 反代"
```

### 4.3 AI 辅助开发体会

- **效率提升**：项目从零到完整可部署，AI 承担了约 70% 的编码工作量
- **最佳实践**：AI 能按业界标准生成 Spring Security、JWT、CORS 等模板代码，降低排查成本
- **局限性**：AI 不了解现有项目环境（如数据库密码、服务器配置），调试阶段仍需人工介入
- **分步策略**：将大需求拆解为小任务（项目初始化 → 用户系统 → 计算模块 → 部署），逐步交付验证

## 六、部署方案

### 6.1 服务器环境

| 项目 | 配置 |
|------|------|
| 云平台 | 阿里云 ECS |
| 操作系统 | Ubuntu 22.04 LTS |
| Web 服务器 | Nginx 1.18 |
| 进程管理 | systemd |
| 版本控制 | Git + GitHub |

### 6.2 部署流程

```
1. 阿里云购买 ECS，配置安全组（22/80/443）
2. apt 安装 JDK17, MySQL8, Python3, Nginx, Git
3. SSH 密钥配置 → GitHub 拉取代码
4. 导入 init.sql 建表
5. Python Flask 配置 systemd 服务
6. 本地 mvn package → scp jar 上传 → systemd 服务
7. 本地 npm run build → scp dist 上传 → Nginx 配置
8. Certbot 配置 HTTPS 证书
```

### 6.3 运维命令

```bash
git pull                     # 更新代码
mvn clean package            # 构建后端（本地）
npm run build                # 构建前端（本地）
systemctl restart meitan-*   # 重启服务
journalctl -u meitan-* -f    # 查看日志
```

## 九、总结

本项目实践了前后端分离 + Python 微服务混合架构，将传统桌面程序升级为 Web 平台。开发过程中借助 Codex 和 Trae 大幅提升编码效率，重点在于合理的架构分层、清晰的 API 设计，以及 AI 辅助下的快速迭代开发。最终完成从需求分析、架构设计、编码实现到服务器部署上线的全流程交付。
